# Sputnik

Minimalist desktop music player: Electron 44, React 19, TypeScript 7, Vite 8,
Tailwind 4, Zustand. A key goal is a small installer, so the app ships no
runtime dependencies: Vite bundles everything.

## Commands

```bash
pnpm dev            # Electron + Vite with HMR
pnpm dev:web        # renderer only, in a browser, with demo data (see preview-ui)
pnpm typecheck      # tsc -b (main, preload, renderer, tests)
pnpm lint           # oxlint
pnpm test           # all Vitest tests (test:unit, test:int, test:coverage)
pnpm format         # Prettier
pnpm dist:win       # Windows installer in release/ (dist:mac, dist:linux)
```

Before finishing any change: `pnpm typecheck && pnpm lint && pnpm test`.

## Map

- `electron/`: main process. `protocol.ts` (`sputnik://`), `library.ts` (import and
  metadata), `covers.ts`, `ipc.ts` + `ipcArgs.ts`, `jsonStore.ts`, `window.ts`, `main.ts`,
  `preload.ts`.
- `shared/`: types, constants, IPC guards and pure logic used by both sides. Never
  imports Electron, Node or the DOM.
- `src/`: renderer. `app/` (user flows, persistence, boot), `audio/` (the `<audio>`
  engine), `stores/` (Zustand), `features/`, `components/`, `hooks/`, `lib/` (pure
  logic), `i18n/`, `demo/`, `test/` (integration tests and fakes).
- The renderer never imports `node:*` or `electron`: it reaches the system only
  through `src/lib/bridge.ts` (`window.sputnik`).

## Rules that are not obvious from the code

- **IPC security**: every channel is a method in `SputnikApi`, a validator in
  `electron/ipcArgs.ts` and a handler registered with `handle()` in `electron/ipc.ts`,
  which checks the sender. Follow the `add-ipc-channel` procedure.
- **Media protocol**: `sputnik://media/<id>` only serves ids in the allowlist. Never put
  file paths in URLs.
- **Size**: `dependencies` in package.json stays empty. Ask before adding any package
  and measure the installer with `release-check`.
- **React Compiler is on**: no `useMemo`, `useCallback`, `memo`, `forwardRef` or
  `defaultProps`. Effects only sync with external systems.
- **Zustand**: select primitives or use `useShallow`; a selector that returns a new
  object loops. Event handlers read actions with `useXStore.getState()` when they fire.
- **Colors**: only theme tokens (`bg-canvas`, `bg-raised`, `text-fg`, `text-fg-muted`,
  `border-line`, `text-accent`), never hex values in components: the cover tint and
  the contrast guarantees (`src/lib/color.ts`) depend on it.
- **Text**: no literals in JSX (oxlint enforces it). Add keys to `src/i18n/es.ts` (the
  reference) and `en.ts`; a missing key fails the typecheck.
- **Accessibility**: icon-only buttons use `IconButton` with a `label`. Tests query by
  role and accessible name, so a missing label fails them.

## Tests

- Unit tests sit next to their module (`foo.test.ts`); integration tests are
  `*.int.test.ts(x)` in `src/test/` and `electron/test/`.
- Renderer integration tests boot the whole app with `renderApp()` (memory bridge,
  `FakeAudio`, fake Media Session). Inject dependencies instead of `vi.mock` on
  internal modules.
- Main-process integration tests use real files in a temp folder; audio fixtures are
  generated by `test/fixtures/makeAudio.ts` (no binaries in the repo).
- Every bug fix comes with a test that fails without it. No snapshot tests.

## Conventions

- Strict TypeScript without `any` (`unknown` + type guards). `interface` for object
  shapes, `type` for unions; `as const` instead of enums.
- Arrow function components with typed props and named exports. Early returns, array
  methods, lookup objects instead of `switch`, `UPPER_SNAKE_CASE` constants, comments
  only when the intent is not obvious.
- camelCase modules, PascalCase components, `useX` hooks. Tailwind, mobile first.
- pnpm. One commit per verified block of work.

## Gotchas

- Windows cannot rename a folder another process watches: Vite ignores `release/`; if
  packaging fails with `EPERM`, stop whatever watches that folder.
- The packaged app fails to start from paths longer than ~200 characters (Chromium
  cannot open its ICU data). Copy test builds to short paths.
- `vite-plugin-electron` launches Electron with `--no-sandbox` by default;
  `vite.config.ts` overrides it so dev keeps the sandbox.
- RIFF INFO tags in WAV files are Latin-1.
